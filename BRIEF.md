# Build brief: docxops

Build a Python library "docxops": Word (.docx) structure operations that an LLM agent calls as tools. Common rules: Python 3.12, works on Windows and Linux. Allowed dependencies only: openpyxl, python-docx, docxcompose, python-pptx, pypdf, pdfplumber, fpdf2, pandas, numpy, jsonschema. No network, no telemetry, no subprocess, no Office automation. Every public operation is a plain function that returns a JSON-serializable report {"ok", "changed", "warnings", "details"} and never raises for user errors. Each ships a JSON Schema in SCHEMAS[name], at most 600 characters. Pytest tests generate their own fixtures. Apache-2.0.

The hard one first: add_toc(path, levels=1-3, title="Contents"). It inserts a real TOC field (w:fldSimple or a complex field with TOC \o "1-3" \h \z \u) AND pre-fills the field result with one hyperlinked entry per heading, each pointing to a bookmark that the function adds to the heading, with the correct TOC 1/2/3 styles. A reader sees a usable table of contents even if fields are never updated. Set w:updateFields in settings.xml so Word refreshes the page numbers on open. Page numbers in the pre-filled result are left blank, never guessed. It must survive being run twice: replace, never duplicate.

Other operations: outline (headings tree, tables count, images count, sections, styles used), add_heading, set_heading_numbering, add_paragraph_after(heading text), replace_text (works across runs without losing formatting of untouched runs; reports matches it could not do safely), add_table (from rows, with a header style), table_from_csv, add_caption (Table/Figure with SEQ fields), cross_reference (to a caption or heading bookmark), header_footer (text, page number field "Page X of Y"), section_break (orientation per section), page_setup, compose (merges documents with docxcompose, keeping styles and numbering), styles_apply (map paragraphs to built-in styles by rule), comments_list.

Tests: the TOC test opens the result with python-docx and checks the field code, the entries, the bookmarks, and that a second add_toc replaces the first. Plus one test per operation.
